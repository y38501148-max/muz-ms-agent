# muz-ms-agent 界面设计约定

界面采用蓝白工作台。保留 Nuxt + Ant Design Vue，配色、间距、表单和反馈统一映射到 ConfigProvider 与 CSS 变量。

- 主色 `#2563eb`，白色内容面，浅蓝灰页面 `#f5f7fb`，正文 `#18243b`。主按钮、选中项、焦点和进度使用蓝色；正误反馈同时显示文字标签。
- 桌面导航 208px，顶栏 60px，内容左右 32px。首页左侧配置按任务分组，右侧集中显示本场安排和开始按钮。
- 间距主要为 8/12/16/18/20/24/32px。主卡圆角 12px，控件圆角 8px，相关字段以网格对齐。
- 字体使用系统字体，标题 28px，正文 14—15px，辅助文案通常 12px。用户输入、原始问答和证据不截断为摘要。
- 首页默认 AI 自主出题与辅导反馈。未配置模型时开始按钮显示「配置模型」；固定题卡模式明确说明无正误判断。
- 回答反馈使用正确、部分正确、有误、信息不足四种状态，并给判断依据。模拟模式面后集中展示。
- 窄屏表单改为单列，方向卡保留两列；导航图标保留可访问名称，主要点击区域约 44px。窗口与页面不靠隐藏横向溢出来掩盖布局问题。
- 支持可见键盘焦点及减少动态效果；异步操作显示处理中，失败保留回答。文案只保留完成操作、理解状态与错误恢复需要的信息。
